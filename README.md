# mmdalam — Mohammad Alemzadeh

Personal website and résumé of **Mohammad Alemzadeh** (محمد عالم‌زاده), Senior Back-End Developer & Technical Team Lead.

- Persian (default): `/`
- English: `/en`

Built with Next.js (App Router) as a fully static site — no back end, no database — ready for Vercel.

## Run locally

```bash
npm install
npm run dev
```

## Deploy on Vercel

Import the repository in Vercel; the framework is detected automatically (build command `next build`).
Optionally set `NEXT_PUBLIC_SITE_URL` (e.g. `https://mmdalam.ir`) so canonical URLs, the sitemap and share cards use your custom domain.

## Editing content

All text lives in `content/fa.ts` and `content/en.ts`; shared contact details and links are in `content/site.ts`.
Project screenshots are in `public/images/projects/`, and the downloadable CV is `public/Mohammad-Alemzadeh-Resume-FA.pdf`.
